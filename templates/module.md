# Module template

Use this structure for each module in Phase 3. Section length depends on the user's level and the module's hour estimate. Don't write filler to make a section look complete.

```markdown
# Module [n]: [Title]
*Syllabus: [week/unit] · Est. [h] hours · Readings: [syllabus readings, cited]*

## Objectives
By the end you can:
1. [Verb] [specific, checkable outcome]
2. ...
(3-5 total)

## Lesson
### [Topic 1 from syllabus]
[Start with an example or problem, then the idea, then a worked example.]
> **Analogy:** [one analogy for the hardest concept]

### [Topic 2 from syllabus]
...

**Covered:** [one line: syllabus topics and reading sections covered; anything deferred and to which module]
[If any topic was thin in the syllabus: "⚠ The syllabus only says '[x]'. I covered [scope]. Tell me if you want more."]

## Practice
*Maps to: [syllabus assignment, or "my own task: no assignment listed this week"]*
1. [O1] [Exercise, from warm-up to harder]
2. ...
**Mini-project (optional):** [scoped to the hour estimate]

<details><summary>Solutions / expected results</summary>

[Short solution or expected output for each exercise, checked against the lesson's code]
</details>

## Quiz
1. [O2] [question]
2. ...
5. [question]

<details><summary>Answers</summary>

1. **[answer]**: [why, and the common wrong answer and why it's wrong]
...
</details>

## Further resources
- [Syllabus reading]: [what to focus on]
- [Title], [Author/Publisher]: [why it's useful]
- [Title] **[unverified]**: [why it might help]

---
✅ Module [n] done: [one-line summary]. Next: Module [n+1], [title]. Say **next** to continue.
```

If the chat interface doesn't render `<details>`, put the answers under a `### Answers` heading after a horizontal rule instead.
